# Mustakim's Kitchen — Premium 3D Food Delivery Website

A luxury 3D food delivery web experience built with Next.js 15, React 19, Tailwind CSS v4, GSAP ScrollTrigger, and Framer Motion.

## 🌟 Features Included

- **3D Halftone Gallery Heading**: Vertical-loop canvas animation with 12 3D orbiting halftone plates around the headline ("WELCOME TO MUSTAKIM'S KITCHEN").
- **Crowd Canvas**: Walking pedestrians, foodies, and couriers beneath the hero title with GSAP timelines.
- **GSAP 3D Stacking Cards (`StickyCard002`)**: ScrollTrigger card sequence scaling, rotating, and stacking signature masterpieces.
- **3D Creative Food Carousel (`FoodCarousel`)**: Swiper 3D creative translation carousel for quick dish selection.
- **3D Tilt Menu Cards (`MenuSection`)**: Framer Motion 3D tilt cards with cursor-following specular glare.
- **Cinematic Showreel (`FoodShowreel`)**: Spring-physics floating cursor "PLAY" pill and 4K fullscreen video modal.
- **3D Thermal Delivery Tracker (`DeliveryTracker3D`)**: Live route simulator with animated courier and temperature-controlled lock monitoring.
- **Progressive Blur (`ProgressiveBlur`)**: Multi-step backdrop-blur overlays for smooth section transitions.
- **Interactive Cart Drawer (`CartDrawer`)**: Slide-out cart with quantity controls, promo code discount calculation (`WELCOME20`), and order checkout.

## 🚀 How to Host on GitHub

### 1. Initialize Git and Commit:
```bash
git init
git add .
git commit -m "Initial commit: Mustakim's Kitchen 3D Food Delivery Website"
git branch -M main
```

### 2. Connect to your GitHub Repository:
Create a new repository on [GitHub](https://github.com/new) (e.g. `mustakims-kitchen`).
Then run:
```bash
git remote add origin https://github.com/YOUR_USERNAME/mustakims-kitchen.git
git push -u origin main
```
